# FSRS-only Scheduling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the FSRS-only migration: every review, reset and read goes through the canonical FSRS tables, every aggregate is one indexed SQL statement, SM-2 and the legacy tables are gone, and a performance doctrine is written down for future agents.

**Architecture:** The write path routes through the existing `fsrs-live.service` (idempotent, serializable, already tested). The read model is SQL-native: two immutable per-revision constants (`decay`, `factor`) plus an `IMMUTABLE` Postgres function `fsrs_retrievability` let every dashboard/analytics query compute retention set-based with no per-card JavaScript. A shared fragment module (`fsrs-sql.ts`) is the single vocabulary for New / Due / Learning / Review / At-risk. Legacy tables are dropped only after a verified replay of the dev database.

**Tech Stack:** Bun 1.3.10, TypeScript 5.9, ElysiaJS, postgres.js 3.4.8 + drizzle-orm 0.45.1 (client is drizzle-wrapped — see `src/db/pg-codecs.ts`), PostgreSQL 15, ts-fsrs 5.4.1, SolidJS + TanStack Solid Query, `bun test` with disposable Postgres databases.

**Spec:** `docs/superpowers/specs/2026-09-08-fsrs-only-design.md`

## Global Constraints

- Work on branch `feat/fsrs-only`, created from `fix/pgclient-codecs`. One commit per task as written below; every commit passes `bun run typecheck`, `cd apps/api && bun test` (dev Postgres up via `docker compose up -d`), `cd apps/web && bun test`.
- Follow `AGENTS.md` §3 verbatim. In particular: raw SQL through `pgClient` must use `src/db/pg-codecs.ts` (`bindTimestamp`, `bindJson` + `::text::jsonb`, `timestampFromRow`); never bind a JS `Date` or an object; timestamps read back are text. Drizzle `db.execute(sql\`…\`)` shares the same client, so **bind `asOf.toISOString()` with a `::timestamptz` cast**, never a `Date`.
- `asOf` is captured once per request in the route/service and passed down. No `NOW()` inside fragments.
- Aliases in every query: `c` = `cards`, `d` = `decks`, `s` = `fsrs_card_states`, `r` = `fsrs_parameter_revisions`, `e` = `fsrs_review_events`.
- Migrations are hand-written, idempotent, no `CONCURRENTLY`, journal `when` strictly increasing. Never run `db:generate` / `db:push`.
- Formatting: 2-space indent, single quotes, semicolons, trailing commas in multiline literals. No new dependencies.
- Deviation from the spec, agreed here: the spec's single `0028` migration is split into `0028_fsrs_curve_expand.sql` (Phase 2: columns, function, indexes — additive) and `0029_fsrs_only_finalize.sql` (Phase 3: drops). Task 27 records this in the spec.
- Postgres test suites (`*.postgres.test.ts`, `*.integration.test.ts`) need `TEST_POSTGRES_ADMIN_URL` (default `postgresql://postgres:postgrespassword@localhost:5435/postgres`) reachable. Every repository they cover must also be exercised through a `drizzle()`-wrapped client (`drizzleWrappedSql`).
- Web rules: no prop destructuring, `class` not `className`, `onInput`, `<Show>/<For>`, pair listeners with `onCleanup`, module-scope reactivity only inside `createRoot`.

```ts
// apps/web/src/pages/study-review-state.ts
export type ReviewRating = 'again' | 'hard' | 'good' | 'easy';

export interface ReviewItem {
  requestId: string;
  cardId: string;
  rating: ReviewRating;
  reviewedAt: string;
  durationMs?: number;
}

export interface ReviewBatchResult {
  applied: number;
  duplicates: number;
  results: Array<{ requestId: string; cardId: string; status: 'applied' | 'duplicate' }>;
}

const MAX_DURATION_MS = 60 * 60 * 1000;

/**
 * One review event. `requestId` makes retries idempotent on the server, so it
 * must be generated once per grade, never per request attempt.
 */
export function buildReviewItem(
  cardId: string,
  rating: ReviewRating,
  shownAtMs: number | null,
  now: Date = new Date(),
  requestId: string = crypto.randomUUID(),
): ReviewItem {
  const item: ReviewItem = {
    requestId,
    cardId,
    rating,
    reviewedAt: now.toISOString(),
  };
  if (shownAtMs !== null) {
    const duration = now.getTime() - shownAtMs;
    if (duration >= 0 && duration <= MAX_DURATION_MS) item.durationMs = duration;
  }
  return item;
}
```

```ts
  factor: number;

/**
 * Same arithmetic as ts-fsrs 5.4.1 `computeDecayFactor`, so
 * `fsrs_retrievability()` in Postgres reproduces `forgetting_curve()` exactly.
 */
export function fsrsForgettingCurveConstants(
  parameters: unknown,
): FsrsForgettingCurveConstants {
  const normalized = normalizeFsrsParameters(parameters);
  const decay = -normalized.w[20]!;
  if (!Number.isFinite(decay) || decay >= 0) {
    throw new ValidationError('FSRS decay (w[20]) must be positive');
  }
  const factor = Number((Math.exp(Math.log(0.9) / decay) - 1).toFixed(8));
  if (!Number.isFinite(factor) || factor <= 0) {
    throw new ValidationError('FSRS forgetting-curve factor must be positive');
  }
  return { decay, factor };
}
```

```ts
// apps/api/src/modules/study/fsrs-sql.ts
import { sql, type SQL } from 'drizzle-orm';

/**
 * Shared vocabulary for canonical FSRS reads through `db.execute(sql\`…\`)`.
 * Aliases are fixed: `c` cards, `s` fsrs_card_states, `r` fsrs_parameter_revisions.
 * `asOf` is bound once per request as ISO text (the client is drizzle-wrapped:
 * a JS Date would not serialise — see src/db/pg-codecs.ts).
 */
export function fsrsAsOf(asOf: Date): SQL {
  return sql`${asOf.toISOString()}::timestamptz`;
}

export function fsrsStateJoin(userId: string): SQL {
  return sql`
    LEFT JOIN fsrs_card_states s
      ON s.card_id = c.id AND s.user_id = ${userId}::uuid
    LEFT JOIN fsrs_parameter_revisions r
      ON r.id = s.parameter_revision_id`;
}

export const FSRS_NEW: SQL = sql`s.id IS NULL`;
export const FSRS_LEARNING: SQL = sql`s.state IN ('learning', 'relearning')`;
export const FSRS_REVIEW: SQL = sql`s.state = 'review'`;

export function fsrsDue(asOf: Date): SQL {
  return sql`(s.id IS NULL OR s.next_review_at <= ${fsrsAsOf(asOf)})`;
}

export function fsrsDueLater(asOf: Date): SQL {
  return sql`(s.id IS NOT NULL AND s.next_review_at > ${fsrsAsOf(asOf)})`;
}

export function fsrsTargetRetention(): SQL {
  return sql`COALESCE((r.parameters->>'request_retention')::double precision, 0.9)`;
}

export function fsrsRetrievability(asOf: Date): SQL {
  return sql`
    CASE WHEN s.id IS NULL THEN NULL
    ELSE fsrs_retrievability(
      s.stability,
      EXTRACT(EPOCH FROM (${fsrsAsOf(asOf)} - s.last_reviewed_at)),
      r.decay,
      r.factor
    ) END`;
}

export function fsrsAtRisk(asOf: Date): SQL {
  return sql`(
    ${FSRS_REVIEW}
    AND ${fsrsDueLater(asOf)}
    AND ${fsrsRetrievability(asOf)} < ${fsrsTargetRetention()}
  )`;
}
```

```ts
import { db } from '../../db';

export interface DueDeckNotification {
  deckId: string;
  deckName: string;
  dueCount: number;
}

/** Decks with at least one due card. Due = no state row, or next_review_at <= asOf. */
export function dueDecksSql(userId: string, asOf: Date, limit: number): SQL {
  return sql`
    SELECT d.id::text AS "deckId", d.name AS "deckName", COUNT(*)::int AS "dueCount"
    FROM cards c
    JOIN decks d ON d.id = c.deck_id AND d.user_id = ${userId}::uuid
    ${fsrsStateJoin(userId)}
    WHERE ${fsrsDue(asOf)}
    GROUP BY d.id, d.name
    ORDER BY "dueCount" DESC, d.name ASC
    LIMIT ${limit}`;
}

export function totalDueSql(userId: string, asOf: Date): SQL {
  return sql`
    SELECT COUNT(*)::int AS total
    FROM cards c
    JOIN decks d ON d.id = c.deck_id AND d.user_id = ${userId}::uuid
    ${fsrsStateJoin(userId)}
    WHERE ${fsrsDue(asOf)}`;
}

export async function getDueDecks(
  userId: string,
  asOf: Date = new Date(),
): Promise<DueDeckNotification[]> {
  const rows = await db.execute<DueDeckNotification>(
    dueDecksSql(userId, asOf, NOTIFICATIONS.MAX_DUE_DECKS),
  );
  return rows.map((row) => ({
    deckId: row.deckId,
    deckName: row.deckName,
    dueCount: row.dueCount,
  }));
}

export async function getTotalDueCount(
  userId: string,
  asOf: Date = new Date(),
): Promise<number> {
  const [row] = await db.execute<{ total: number }>(totalDueSql(userId, asOf));
  return row?.total ?? 0;
}
```

```ts
        EXISTS (SELECT 1 FROM decks WHERE id = ${deckId}::uuid AND user_id = ${userId}::uuid) AS owned,

        (SELECT COUNT(*)::int FROM scored WHERE status = 'new') AS "newCount",
```

```ts
export async function getForecast(userId: string, days: number, asOf = new Date()) {
  const clampedDays = Math.min(Math.max(days, 1), 90);
  const rows = await db.execute<{ offset: number; atRiskCount: number; avgRetention: number | null }>(sql`
    WITH states AS (
      SELECT s.stability, s.last_reviewed_at, r.decay, r.factor, ${fsrsTargetRetention()} AS target
      FROM fsrs_card_states s
      JOIN fsrs_parameter_revisions r ON r.id = s.parameter_revision_id
      WHERE s.user_id = ${userId}::uuid
    ),
    horizon AS (SELECT generate_series(0, ${clampedDays - 1}) AS offset)
    SELECT
      h.offset,
      COUNT(x.retention) FILTER (WHERE x.retention < x.target)::int AS "atRiskCount",
      AVG(x.retention)::double precision AS "avgRetention"
    FROM horizon h
    LEFT JOIN LATERAL (
      SELECT fsrs_retrievability(
               st.stability,
               EXTRACT(EPOCH FROM ((${fsrsAsOf(asOf)} + h.offset * interval '1 day') - st.last_reviewed_at)),
               st.decay, st.factor
             ) AS retention,
             st.target
      FROM states st
    ) x ON true
    GROUP BY h.offset
    ORDER BY h.offset
  `);
  const byOffset = new Map(rows.map((row) => [Number(row.offset), row]));
  const forecast: ForecastDay[] = [];
  for (let offset = 0; offset < clampedDays; offset += 1) {
    const row = byOffset.get(offset);
    forecast.push({
      date: new Date(asOf.getTime() + offset * 86_400_000).toISOString().slice(0, 10),
      atRiskCount: row?.atRiskCount ?? 0,
      avgRetention: row?.avgRetention == null ? 1 : Math.round(row.avgRetention * 1000) / 1000,
    });
  }
  return { forecast };
}
```

```ts
async function explainUsesIndex(statement: SQL, indexName: string) {
  const { sql: text, params } = db.dialect.sqlToQuery(statement);
  await raw.begin(async (transaction) => {
    await transaction.unsafe('SET LOCAL enable_seqscan = off');
    const rows = await transaction.unsafe<Array<Record<string, string>>>(
      `EXPLAIN (FORMAT TEXT) ${text}`,
      params as unknown[],
    );
    const plan = rows.map((row) => Object.values(row)[0]).join('\n');
    expect(plan).toContain(indexName);
    expect(plan).not.toMatch(/Seq Scan on fsrs_card_states/u);
  });
}
```

```ts
export interface DueDeckLike { deckId: string; dueCount: number }

export function applyReviewedCards<T extends DueDeckLike>(decks: T[], deckId: string, by: number): T[] {
  return decks.flatMap((deck) => {
    if (deck.deckId !== deckId) return [deck];
    const dueCount = Math.max(0, deck.dueCount - by);
    return dueCount === 0 ? [] : [{ ...deck, dueCount }];

}
```
